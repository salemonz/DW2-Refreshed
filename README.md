# DW2 Refreshed

Releases of the **Refreshed** mods for *Distant Worlds 2*: a family of mods that refresh the game's look and feel.

This repository holds release downloads only. Each mod version is a release named `<Mod-name>-v<version>` on the [Releases](../../releases) page. Guides and explanations for every mod are in the [Wiki](../../wiki).

## Installing

All Refreshed mods need **[DW2 Mod Launcher](https://github.com/lucky-wolf/DW2-Mod-Launcher)**.

- **Steam:** subscribe to the mod on the Steam Workshop, then enable it in DW2 Mod Launcher.
- **Without Steam (GOG, direct purchase) or by choice:** open DW2 Mod Launcher, click **Browse Mod Catalog**, find the mod and install it. Mods installed this way update automatically.
- **By hand:** download the mod's `.zip` from [Releases](../../releases), extract it into `<Distant Worlds 2>\mods\`, then enable it in DW2 Mod Launcher.

## Problems and suggestions

Open an [issue](../../issues) naming the mod, its version, and what you saw. A copy of the launcher's problem summary (About > Copy Problem Summary) helps.
